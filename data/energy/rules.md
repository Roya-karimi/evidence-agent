All depths in the records are in metres.

1. A stated value is supported if it equals the record value at the precision stated. If the claim says "about" or "approximately", allow a difference of up to 1% of the record value.
2. A stated value that differs from the record value beyond that tolerance is contradicted.
3. If the claim uses another unit (for example feet), convert before comparing (1 ft = 0.3048 m). A value that only matches if the unit is ignored is contradicted.
4. Measured depth and vertical depth are different quantities. Never use one as evidence for the other.
5. Record not found, or the needed value missing: insufficient_evidence.
6. Claims the records do not address (for example current safety, cost, or future production): insufficient_evidence.
